# Интерфейс лабораторной №10

Vue 3 + TypeScript показывает реальные ответы FastAPI по циклам шага. Запуск
описан в корневом README. В режиме разработки Vite направляет `/api` на
`http://127.0.0.1:8000`. Для отдельного сервера задайте `VITE_API_BASE_URL`.

Интерфейс не содержит обученной модели: перед предсказанием загрузите один из
зарегистрированных локальных файлов `terrain_predictor*.joblib`. Точные
SHA-256 закреплены в `src/research_graph/api/trusted_models.json`.
