# Интерфейс лабораторной №10

Vue 3 + TypeScript показывает реальные ответы FastAPI по циклам шага. Запуск
описан в корневом README. В режиме разработки Vite направляет `/api` на
`http://127.0.0.1:8000`. Для отдельного сервера задайте `VITE_API_BASE_URL`.

Рабочая модель входит в Python-пакет и загружается API при запуске. Для
предсказания загружать её вручную не нужно. Другой зарегистрированный артефакт
можно выбрать в интерфейсе; его SHA-256 закреплён в
`src/research_graph/api/trusted_models.json`. Для исходного PS CSV необходимо
явно выбрать сторону протеза. Скачиваемый результат содержит признаки каждого
цикла, предсказание и вероятности классов.
