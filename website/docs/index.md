# Assistive Gait Research

Будущая публикация исследования классификации условий ходьбы пользователей
протезов нижних конечностей по IMU-сигналам.

Текущий статус: инфраструктура ЛР1, EDA всех 20 участников NTNU и локальное
воспроизведение Random Forest из Wassall et al. (2026). Выполненные ноутбуки
находятся в `notebooks/` в корне проекта; исторический текстовый отчёт EDA —
в `docs/eda_report.md`. Итоговая модель для сервиса ещё не подготовлена.
Этот сайт ещё не собирается и не публикуется.

Планируемые разделы: данные, методология, эксперименты, метрики,
ограничения и инструкции воспроизведения.
