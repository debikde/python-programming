# Промпты использования ИИ в лабораторной №10

**Инструмент:** Codex. **Дата:** 25.10.2026. Ниже сохранены пользовательские
запросы, по которым создавались программная часть и интерфейс. Пример с
ипотекой из описания лабораторной рассматривался как образец требований,
а не как источник данных проекта.

## Основной запрос

> Продолжи работу в существующем проекте Assistive Gait Research. Изучи существующий код и требования лабораторной №10.
>
> **Цель — полностью выполнить программную часть лабораторной №10 на основе уже проведённого исследования NTNU, не переписывая ML-пайплайн.**
>
> 1. **Заверши подготовку модели.** Используй выбранный Random Forest со 140 признаками без каденса. Проверь совместимость сохранённого `TerrainPredictor` с API. Сохрани результаты независимой проверки модели на четырёх участниках. После фиксации оценки можно обучить отдельную финальную модель на всех 20 участниках, явно разделив экспериментальный и рабочий артефакты.
> 2. **Выполни требования к сравнению моделей.** Используй уже полученные результаты Random Forest, Logistic Regression и Extra Trees. Подготовь сравнительную таблицу ROC-AUC OvR, accuracy, macro-F1 и balanced accuracy. Объясни выбор модели по ROC-AUC, как требуется в лабораторной, с учётом качества на новых участниках. Не подбирай параметры по отложенному тесту.
> 3. **Реализуй FastAPI** с обязательными маршрутами: `POST /upload-model`, `POST /predict`, `POST /predict-from-csv`. Учитывай, что единица предсказания — цикл шага, а не отдельный отсчёт датчика. Не загружай произвольные недоверенные pickle/joblib-файлы.
> 4. **Создай простой frontend на Vue 3 + TypeScript.** Нужны загрузка модели, ввод или загрузка данных, таблица предсказаний, вероятности классов и информация о качестве модели. Показывай ограничения модели. Для кодов Terrain 8/9 не используй неподтверждённые названия.
> 5. **Добавь тесты и CI в SourceCraft.** Проверяй корректные и ошибочные запросы, загрузку CSV, согласованность предобработки с ноутбуком, работу модели и сборку frontend. Обнови README с инструкциями запуска и демонстрации. Сохрани промпты использования ИИ для отчёта по лабораторной.
> 6. **Сохрани исследовательские результаты.** Не меняй существующие ноутбуки и полученные метрики. Добавь краткий раздел с ограничениями модели: качество на новых участниках, зависимость от магнитометра, ошибки классов 6/7 и проблемы разметки NTNU. Эти материалы позднее будут использованы для научного сайта.
>
> **Требования к реализации:** простой и понятный Python-код, минимум лишних абстракций, переиспользование существующих функций. Интерфейс должен работать с реально обученной моделью, а не демонстрационными предсказаниями.
>
> Выполни работу непосредственно в репозитории, запусти тесты и проверь работу API и frontend. В конце кратко укажи, какие требования лабораторной выполнены, какие файлы созданы и что осталось сделать.
>
> Пока не создавай научный сайт и не запускай новые большие ML-эксперименты.

## Уточнение пользователя

Дополнительные промпты для генерации интерфейса не использовались. Код
