# Отчёт по лабораторной работе №1

**Проект:** Assistive Gait Research. **Дата локальной проверки:** 21.10.2026.
**Уровень:** базовый и «Базовый+» по требованиям приложенного задания.

Реализован устанавливаемый пакет `research_graph` в src-layout с CLI `rg`:
`version` показывает версию 0.1.0, `check-config` проверяет настройки и выводит
безопасную сводку. `Settings(BaseSettings)` читает `RG_*` и необязательный `.env`,
валидирует таймаут, параллелизм и уровень логирования. Создание каталога данных
идемпотентно и не перезаписывает существующие файлы. Токен исключён из repr
настроек и вывода CLI; ошибки не печатают значения конфигурации.
Логирование выводит время, уровень, имя логгера и сообщение в stderr,
заменяет обработчики при повторной настройке и ограничивает сторонние логи.

Выбраны Python 3.12, uv и lock-файл. Настроены Ruff, строгий mypy для `src`
и `tests`, pytest со строгими маркерами, branch coverage и порогом 70%.
Pre-commit использует зависимости основного окружения через `uv run --locked`,
включая проверки YAML и текстовых файлов. GitHub Actions подготовлен для push
и pull request с установкой из lock-файла без `.env`, данных и токенов.

Архитектура разделяет источники данных, схемы, этапы обработки, хранение
артефактов и будущий API. Их модули содержат только docstrings. Подготовлены
документы для frontend, научного сайта и ноутбуков, описание NTNU Dataset
и план исследований. Данные и результаты исключены из Git; сохранены `.gitkeep`.
ML-алгоритмы, API и интерфейс в ЛР1 не реализовывались.

Практические сложности: uv отсутствовал в PATH текущего терминала — найден
установленный исполняемый файл, его каталог добавлялся в PATH проверочных
процессов. Сетевая песочница блокировала PyPI; синхронизация выполнена после
разрешённого запуска вне неё. Windows-launcher mypy и pytest сообщал об ошибке
канонизации пути даже после переустановки пакетов из lock-файла; запуск вне
песочницы подтвердил работоспособность окружения. Тесты изолируют переменные,
рабочую папку, кэш настроек и обработчики логирования.

Фактически выполнены `uv sync`, Ruff lint и format, строгий mypy
(24 Python-файла), pytest (**33 теста, 100% покрытия строк и ветвей**),
`rg --help`, `rg version`, `rg check-config`. Все перечисленные проверки прошли.
Полный pre-commit также прошёл: проверки кода, YAML, пробелов, окончаний строк,
конфликтов слияния и размера файлов.

Локальный `origin` связан с `debikde/python-programming`. Работа оформлена
поэтапными локальными коммитами; push и тег `lab1` не выполнялись.
Для ручной проверки остаются оценка
работы преподавателем и согласование будущей публикации. После разрешения
публикации нужно сверить удалённую историю и ветку, проверить первый запуск
Actions и CI-бейдж. Удалённый CI сейчас не запускался.
