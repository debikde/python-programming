# Планируемый датасет

В задании выбран **IMU data from lower-limb prosthetic users traversing real-world
terrain** (NTNU), DOI: [10.18710/U8RGDL](https://doi.org/10.18710/U8RGDL).

Планируемое назначение — исследование двигательной активности пользователей
протезов нижних конечностей и классификация условий ходьбы по измерениям
носимых инерциальных датчиков. Это исследовательский прототип, а не клиническая
система диагностики.

На этапе ЛР1 датасет не скачан и не исследован. Название и DOI взяты из задания;
содержимое карточки источника при подготовке не удалось получить.
Структура файлов, названия колонок, частоты измерений, единицы, состав участников
и формат разметки пока не подтверждены. Результатов анализа нет.

Перед подключением необходимо проверить доступность и версию данных, условия
лицензии и цитирования, состав файлов, единицы и временные метки, пропуски,
классы и доступность идентификаторов участников для корректного разделения выборки.
Лицензии этого репозитория не заменяют условия использования исходных данных.

Исходные файлы будут храниться в `data/raw/`, производные — в `data/processed/`.
Git отслеживает только `.gitkeep`; данные и результаты не включаются в репозиторий.
