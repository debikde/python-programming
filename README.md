# Assistive Gait Research

Исследовательский проект для анализа ходьбы пользователей протезов нижних
конечностей по данным IMU. Начальный этап: упаковка Python-проекта и окружение.

Требования: Python 3.12, uv и Git.

```powershell
uv sync --locked
```

Исходный пакет расположен в `src/research_graph`. Зависимости зафиксированы
в `uv.lock`. CLI, тесты и исследовательские модули добавляются следующими этапами.
